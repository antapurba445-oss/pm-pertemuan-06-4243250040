# Wisata Sumatera Utara

Aplikasi Flutter untuk menjelajahi destinasi budaya, sejarah, dan religi di
Sumatera Utara. Daftar destinasi dapat difilter, dibuka ke halaman detail, dan
diakses melalui navigasi Destinasi/Tentang.

## Menjalankan aplikasi

Pastikan Flutter 3.47 atau yang lebih baru tersedia, lalu jalankan:

```shell
flutter pub get
flutter run -d chrome
```

## Pengujian

```shell
flutter test
```
